LWF Alraune Hotkeys
Lazy Witch's Factory の農耕アルラウネにキーで命令を出す MOD
Give orders to Farming Alraune with hotkeys in Lazy Witch's Factory

────────────────────────────────
入れかた
────────────────────────────────

1. BepInEx 5 を落として、ゲームのフォルダ
   （LazyWitchsFactory.exe と同じ場所）へ展開する

     https://github.com/BepInEx/BepInEx/releases
     BepInEx_win_x64_5.4.x.zip

2. 一度ゲームを起動して終了すると、BepInEx/plugins などが作られる

3. LwfAlrauneHotkeys.dll を BepInEx/plugins/ に入れる

4. ゲームを起動する。農耕アルラウネにカーソルを載せて G を押すと
   カーソルを載せたときの情報パネルに「交配 - 植物」などが出る

MOD管理ソフトを使うなら Thunderstore から

     https://thunderstore.io/c/lazy-witchs-factory/p/KiyonakaNata/LwfAlrauneHotkeys/

────────────────────────────────
使いかた
────────────────────────────────

農耕アルラウネにカーソルを載せて
  G → 交配
  H → 現金
  J → 採掘
キーを押したままなぞる → 通った農耕アルラウネ全部に同じ命令

キーを変えるなら BepInEx/config/kiyonakanata.lwfalraunehotkeys.cfg

────────────────────────────────
消しかた
────────────────────────────────

BepInEx/plugins/LwfAlrauneHotkeys.dll を消す
設定も消すなら BepInEx/config/kiyonakanata.lwfalraunehotkeys.cfg

────────────────────────────────

Lazy Witch's Factory ver 0.30.1 / BepInEx 5.4.23.5 で確認
非公式のMOD、公式のサポート対象外

説明は GitHub

     https://github.com/KiyonakaNata/lwf-alraune-hotkeys

English
────────────────────────────────

Install

1. Unpack BepInEx 5 (win x64) into the game folder

     https://github.com/BepInEx/BepInEx/releases

2. Start the game once and quit, so BepInEx/plugins is created

3. Put LwfAlrauneHotkeys.dll into BepInEx/plugins/

4. Start the game. Hover over a Farming Alraune and press G.
   The info panel under the cursor shows Crossbreeding - Plants or similar

With a mod manager, install from Thunderstore

     https://thunderstore.io/c/lazy-witchs-factory/p/KiyonakaNata/LwfAlrauneHotkeys/

Use

Hover over a Farming Alraune and press
  G → Crossbreeding
  H → Cash
  J → Mining
Hold the key and sweep → the same order for every Farming Alraune passed

Change keys in BepInEx/config/kiyonakanata.lwfalraunehotkeys.cfg

Remove

Delete BepInEx/plugins/LwfAlrauneHotkeys.dll
Delete BepInEx/config/kiyonakanata.lwfalraunehotkeys.cfg to drop the settings

Tested with Lazy Witch's Factory ver 0.30.1 / BepInEx 5.4.23.5
Unofficial mod, not supported by the developer

     https://github.com/KiyonakaNata/lwf-alraune-hotkeys
