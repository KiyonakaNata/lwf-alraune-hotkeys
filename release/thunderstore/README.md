# LWF Alraune Hotkeys

Give orders to Farming Alraune with hotkeys in **Lazy Witch's Factory**.

## Orders by key

- Hover over a Farming Alraune and press `G` → Crossbreeding
- `H` → Cash
- `J` → Mining
- Hold the key and move the cursor → every Farming Alraune you pass gets the same order
- Keys do nothing over the inventory or a window
- Keys can be changed

![Orders by key](https://raw.githubusercontent.com/KiyonakaNata/lwf-alraune-hotkeys/main/img/hotkeys.webp)

## Settings

- Change keys in the mod manager's Config editor (`kiyonakanata.lwfalraunehotkeys.cfg`)
- Key names: `G`, `F5`, `Digit1`, `Numpad1`, … `None` turns a key off
- `Apply while held` = `false` → only the one under the cursor when the key goes down
